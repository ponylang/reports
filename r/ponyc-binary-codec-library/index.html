Add binary_codec package

A combinator library for bidirectional binary parsing and building. Define a Codec[A] once and it handles both decoding bytes into A and encoding A back to bytes.
15 files changed +2,606

Motivation

Pony programs that speak binary protocols (TCP, UDP, file formats) need to decode incoming bytes and encode outgoing values. Without a library, every project writes its own ad-hoc parsing with manual offset arithmetic, byte-shifting, and error checking. This is repetitive, error-prone, and impossible to test in isolation.

The binary_codec package provides a composable, type-safe approach: small primitive codecs (U16BE, BitsU8(4), Bytes(16)) compose into larger structures via combinators (Seq4, Iso, FlatZip, Discriminated). A single codec definition drives both directions, so parsing and serialization can't diverge.

The library is bit-native. Sub-byte fields (4-bit nibbles, 1-bit flags, 13-bit offsets) work the same way as byte-aligned fields. Errors are data: InsufficientData means "wait for more bytes," MalformedData means "this data is wrong." FrameDecoder uses this distinction to implement zero-copy TCP stream framing.

Core trait and error types

New trait val Codec[A: Any val]
A bidirectional codec that decodes bytes into a value and encodes a value into bytes. Codecs are val — immutable and shareable across actors. The bit offset lets sub-byte fields compose naturally.
  • fun decode(data: Array[U8] val, offset: USize): ((A, USize) | DecodeError)
  • fun encode(value: A): (Array[U8] val | EncodeError)
New primitive InsufficientData
Returned when decode needs more bytes than are available. In streaming, this means "wait for more data."
  • fun string(): String iso^
New class val MalformedData
Returned when decode encounters structurally invalid data — a literal mismatch, an unknown tag, a constraint violation. No additional data will fix it.
  • new val create(message': String, bit_offset': USize = 0)
  • fun message(): String
  • fun bit_offset(): USize
  • fun string(): String iso^
New type DecodeError is (InsufficientData | MalformedData)
The error union returned by decode.
New class val EncodeViolation
Returned when encode fails — a value doesn't fit the codec's constraints or the output isn't byte-aligned.
  • new val create(message': String)
  • fun message(): String
  • fun string(): String iso^

Architecture

Primitive codecs (U16BE, BitsU8, Bytes, etc.) implement the Codec trait directly. Combinators compose codecs: Seq for tuples, Iso for type mapping, FlatZip for dependent parsing, Discriminated for tagged unions, Many/Count for repetition. All combinators are themselves codecs, so they compose recursively.

FrameDecoder wraps any composed codec for TCP streaming, using the InsufficientData/MalformedData distinction to separate "wait for more" from "corrupt data." It notifies the application through the FrameNotify interface.
